# UK-Retail-Sales-Power-BI-Dashboard
Interactive Power BI dashboard analysing UK retail sales, profit, regions, categories, products and monthly trends.

## Project Overview
This project presents an interactive Power BI dashboard developed to analyse UK retail sales performance and identify key business trends across sales, profit, regions, product categories and monthly performance.

## Dashboard Features
- Sales and profit KPI analysis
- Regional sales performance
- Category and product performance
- Monthly sales trends
- Interactive filters and slicers
- Clear visualisation of key business insights

## Skills Used
- Power BI
- Data Visualization
- Data Analysis
- Power Query
- DAX
- Dashboard Design

## Tools
Microsoft Power BI | Power Query | DAX
